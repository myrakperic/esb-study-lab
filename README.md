# ESB Study Lab

An interactive study site for Entrepreneurship and Small Business certification preparation. It runs entirely in the browser and can be hosted as a static site with GitHub Pages.

## Features

- 14 interactive practice tests
- Two randomized 45-question full-length simulations with 50-minute timers
- A 40-question focused exam containing 20% SWOT analysis, 30% course concepts, and 50% business mathematics
- Core Concepts includes directions plus multiple-choice, fill-in-the-blank, matching, binary, and open-ended items
- 72 interactive flashcards organized across six course domains
- Immediate or end-of-test explanations, depending on the test mode
- Domain-level performance summaries
- Automatic score and flashcard-mastery saving in the browser

## Use locally

Open `index.html` in a browser. No installation, build command, account, or internet connection is required.

## Publish with GitHub Pages

1. Create a GitHub repository, such as `esb-study-lab`.
2. Push the contents of this folder to the repository's `main` branch.
3. Open **Settings → Pages** in the GitHub repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

The site will be available at a URL similar to:

`https://YOUR-USERNAME.github.io/esb-study-lab/`

All asset paths are relative, so the site works from a GitHub Pages project subdirectory.

## Privacy and saved progress

Test scores and flashcard mastery are stored with `localStorage` in each visitor's browser. The site has no server component and does not send study progress to the repository owner. Progress does not automatically transfer between browsers or devices.

## Content note

The study bank contains 276 original questions, twelve focused tests, two randomized 45-question full-length simulations, and 72 flashcards. It is an independent study aid based on the six domains in the GMetrix ESB International course. It does not reproduce official certification exam questions and is not an official GMetrix or Certiport product.
